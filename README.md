# CINEMA — совместный просмотр VK Видео

Лёгкий сайт из `tech.md`: HTML/CSS/JavaScript без UI-фреймворка, Node.js и WebSocket. Видео идёт напрямую из VK; сервер передаёт состояние, участников и чат.

## Запуск

Серверу нужен Node.js 22 или новее. В PowerShell используйте `npm.cmd`, если политика Windows блокирует `npm.ps1`.

```powershell
cd E:\MOVIE
npm.cmd ci
npm.cmd run build
npm.cmd start
```

Открыть **http://localhost:3000**. Ввести никнейм, создать комнату, открыть видео и скопировать приглашение.

Для других устройств в локальной сети открыть сайт по LAN-адресу компьютера, например `http://192.168.1.10:3000`. Приглашение копируется с тем же адресом, который открыт в браузере: `localhost` работает только на своём компьютере. При необходимости разрешить входящие подключения TCP 3000 в брандмауэре.

Сборка `npm.cmd run build` нужна после изменения клиента. `npm.cmd run dev` перезапускает сервер при изменениях серверного кода.

## Возможности

- Гостевая сессия в HttpOnly cookie, никнейм в браузере, проверка уникальности имён внутри комнаты.
- Случайный 192-битный адрес комнаты. Сервер проверяет права ведущего и версии команд.
- Передача управления участнику; автоматический выбор наиболее давно подключённого участника через 60 секунд отсутствия ведущего.
- Состояние видео с серверным временем, периодическая коррекция каждые 5 секунд при отклонении более 1,5 секунды, ручная синхронизация. Оценка смещения часов по ping/pong.
- Обработка событий рекламы и ограничений autoplay. Буферизация одного участника не ставит остальных на паузу.
- Чат: 200 сообщений в памяти/на диске, по 50 при загрузке истории, максимум 2000 символов, ограничение 5 сообщений за 5 секунд.
- Enter / Shift+Enter, безопасный текст, сохранение позиции при чтении истории, индикатор новых сообщений.
- Адаптивная тёмная тема с увеличенным шрифтом. В полном экране автоматически появляется плавающий мини-чат снизу справа с тремя последними сообщениями и полем ответа; «Вся история» открывает боковую панель, «Мини-чат» возвращает компактный вид, «Чат» скрывает или показывает панель. Видео не пересоздаётся. Длинные сообщения сокращены до двух строк в мини-чате; полный текст доступен в истории. Есть резервный полноэкранный режим в пределах окна.
- Переподключение с растущей задержкой; один плеер, очистка обработчиков при смене видео.
- Отдельная совместимая сборка: `http://localhost:3000/?legacy=1`, для комнаты добавить `?legacy=1` к её адресу. Цели сборки: Chrome 109 / Firefox 115. Это не подтверждает работу VK на Windows 7.

## Ссылки VK

Принимаются публичные ссылки `https://vk.com/video-123_456`, `https://vkvideo.ru/video-123_456`, ссылки с `z=video…`, адреса официального встраивания и код `<iframe>` из **Поделиться → Экспортировать**. Из HTML извлекается только `src`, проверяются домен и идентификаторы; пользовательские атрибуты, скрипты и стили не исполняются. `hash` сохраняется, если он есть в коде встраивания.

Обычная ссылка может не содержать нужный VK параметр `hash`. В таком случае используйте код экспорта. Ограничения доступа VK, авторизацию и запрет встраивания сайт не обходит. При отсутствии ответа API отображается уведомление; комната и чат продолжают работать.

Используется официальный [VK VideoPlayer API](https://vk.com/js/api/videoplayer.js). Реклама обрабатывается по событиям `adStarted` / `adCompleted`. Если VK не прислал событие, после рекламы следует нажать «Синхронизироваться». Собственная кнопка полного экрана сохраняет чат; встроенная кнопка VK управляет только самим iframe.

## Данные и свой сервер

`data/state.json` содержит комнаты, последние сообщения и хеши случайных токенов гостевых сессий. Запись атомарная, с задержкой до 250 мс; штатное завершение сохраняет данные. При аварийном отключении питания последние события могут не сохраниться. Пустые комнаты удаляются через 24 часа; сессии живут 30 дней. При перезапуске сервера соединения восстановятся, ведущему предоставляется новый 60-секундный период возврата.

Для работы в интернете запустите **один процесс Node.js** за reverse proxy с HTTPS и поддержкой WebSocket. Файлы `dist` сами по себе не обеспечивают комнаты. Для нескольких экземпляров сервера потребуется общее хранилище и распределённый обмен событиями.

Переменные окружения:

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `PORT` | `3000` | Порт HTTP/WS |
| `HOST` | `0.0.0.0` | Адрес прослушивания; за proxy можно поставить `127.0.0.1` |
| `PUBLIC_ORIGIN` | не задана | Точный внешний origin, например `https://watch.example.com` |
| `COOKIE_SECURE` | не задана | `1` для Secure cookie за HTTPS |

Пример Nginx приведён в `deploy/nginx.conf`. Каталог `data` должен сохраняться между перезапусками. Не публикуйте его как статику.

## Проверки

```powershell
npm.cmd test
npx.cmd playwright install firefox
npm.cmd run test:browser
npm.cmd run test:vk
npm.cmd run test:soak
```

Браузерные тесты используют установленный Chrome и Firefox из Playwright. `test:browser` проверяет интерфейс и протокол с **тестовой реализацией API плеера**; `test:vk` отдельно обращается к настоящему VK в обоих браузерах. Для другого ролика задайте `VK_TEST_EMBED` полным адресом iframe с `js_api=1`. `test:soak` по умолчанию идёт 2 часа и проверяет сервер комнат/чата; продолжительность в секундах задаётся через `SOAK_SECONDS`.

Результаты и скриншоты пишутся в `test-results/`. Статус критериев ТЗ и ограничения — в [TESTING.md](TESTING.md).

Бесплатное размещение для просмотра раз в неделю: [HOSTING.md](HOSTING.md). Готовые настройки Render Free находятся в `render.yaml`.
